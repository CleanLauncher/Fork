# Launcher v111.0.5

## Bug Fixes

- Fixed Snap package command path to match CMAKE_INSTALL_PREFIX=/usr install location (usr/bin/launcher)
- Fixed Flatpak build by moving env block inside build-options and using --repo flag for ostree repository
- Restored strict Valgrind flags (error-exitcode, errors-for-leak-kinds) for memory leak detection
- Fixed release workflow tar source excluding release-files directory
- Fixed release checksum generation by restoring working directory after checksum loop
- Fixed Qt 6.4 compatibility: replaced QCheckBox::checkStateChanged with QCheckBox::toggled

- Added openjdk-17-jdk-headless to Snap build-packages and CMAKE_INSTALL_PREFIX=/usr
- Added OpenJDK 17 module to Flatpak manifest with correct /app/jdk/jdk install path
- Added website sync workflow to mirror website/ directory to CleanLauncher/website repository
