# Launcher v111.0.4

## Bug Fixes

- Fixed INI unescape to match C++ parser behavior: unknown escape sequences now strip the backslash instead of preserving it
- Fixed clang-format violations in launcher_core.h for consecutive declaration alignment
- Removed unsupported Valgrind options (time-unit, redo-last-malloc, keep-stacktraces, delta-stacktrace, cleanup-default, expansion, initial-heap-size, auto, inline-alloc) for ubuntu-24.04 compatibility

## Features

- Added Rust HTTP client crate with retry, resume download, and FFI bindings
- Added Rust settings crate with INI parsing, typed getters, defaults, and FFI bindings
- Added mod_metadata crate with CurseForge/Modrinth project and version structs

## Packaging

- Removed old v111.0.2 task spec document
