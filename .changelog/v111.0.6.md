# Launcher v111.0.6

## Bug Fixes

- Added Valgrind suppressions file for Qt, GLib, OpenSSL, and system library false positives
- Fixed Valgrind per-process XML reports (valgrind-%p.xml) to prevent child process report overwrites
- Used absolute paths for Valgrind suppressions and XML output to handle test working directories
- Added versioning rollover rule: at x.y.9 version rolls to x.(y+1).0
- Release workflow now fails instead of deleting existing releases

## Packaging

- Added valgrind.supp suppressions file for known false positive memory leak patterns
